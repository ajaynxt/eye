# Irisora Eye Institute Demo

An original fictional eye-clinic and ophthalmology website concept created for the AJAYNXT portfolio.

## Included

- Original Irisora SVG logo
- Premium responsive design
- Cataract, LASIK, retina, glaucoma, paediatric and cornea sections
- Treatment filters and modal
- Fictional doctor profiles and doctor finder
- Appointment form with WhatsApp lead flow
- Non-diagnostic symptom navigator
- Urgent eye-care disclaimer
- Optical section
- Fictional centre locator
- Patient education and FAQ
- Website-price enquiry
- Mobile sticky actions
- SEO, JSON-LD, robots, sitemap, manifest and 404 page
- GitHub Pages CNAME

## Important

This is not an operational medical service. It does not diagnose, treat, store patient records or create appointments. Before commercial deployment, replace all fictional content with verified clinic data and complete clinician review, privacy, security, consent, accessibility, legal and integration testing.

## Deploy on GitHub Pages

1. Upload all files to the repository root.
2. Open Settings → Pages.
3. Choose Deploy from a branch.
4. Select main and /root.
5. Set the custom domain to `eye.ajaynxt.com`.

## DNS

- Type: CNAME
- Name: eye
- Value: ajaynxt.github.io
- TTL: Default or 30 minutes
